# Prism for Mac

Downloads and automatic updates for **Prism**, one app for every AI:
Claude Code, Codex, Gemini CLI (on your Mac or over SSH) and API models.

**Download:** open the [latest release](https://github.com/fedotov-team/prism-releases/releases/latest)
and get `Prism-…-macOS.dmg`. Works on Apple Silicon and Intel, macOS 11+.

First launch: System Settings → Privacy & Security → **Open Anyway**
(the app is not signed with an Apple developer account).

After that, Prism updates itself (Settings → About → Check for updates).
Updates are signed; the app only accepts files signed by the Prism build.

This repo holds only the app files. The source code is private.
